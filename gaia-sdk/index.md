# Gaia SDK reference

Self-contained API reference for authoring the Gaia DSL directly via the Python SDK — the **primary** authoring path. Generated by introspecting the public API surface (no mkdocs/sphinx needed).

Start with **`CHEATSHEET.md`** (one page, every verb/term/distribution with a copy-pasteable example), then dive into the per-module reference:

- [`gaia.engine.lang`](gaia_engine_lang.md) — 97 public symbols
- [`gaia.engine.bayes`](gaia_engine_bayes.md) — 6 public symbols

Author your DSL directly in `src/<pkg>/__init__.py` (and your own modules); the `gaia author` CLI is an optional convenience that writes into the composed `authored/` submodule. See `docs/for-users/authoring-workflow.md` for the full model.
